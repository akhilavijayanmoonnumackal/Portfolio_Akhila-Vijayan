Ticksow Quiz APP (MERN + Flutter)

A responsive and interactive quiz platform designed for engaging learning experiences. Built with the Flutter(another person did it) and MERN stack (MongoDB, Express.js, React.js, Node.js), Ticksow enables users to participate in timed quizzes, track scores, and view results instantly.

Key Features:
  • User Authentication: Secure login/signup using JWT-based authentication.
  • Dynamic Quiz Management: Admins can create, edit, and delete quizzes with multiple-choice questions.
  • Timed Quizzes: Optimized for desktop, tablet, and mobile devices using Tailwind CSS.
  • Responsive UI: Allows potential clients to reach out easily.
  • Data Storage: MongoDB database for scalable storage of quizzes, users, and results.
