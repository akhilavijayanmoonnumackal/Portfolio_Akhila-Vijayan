VENDORA E-Commerce Application for Vendors & Customers (Ongoing)

Vendora is a dynamic MERN stack-based e-commerce platform that connects vendors and customers. Customers can seamlessly browse and purchase products, while vendors can register, submit necessary documents, and await admin approval to start selling on the platform. The system ensures a secure and efficient vendor verification process, and vendors receive their credentials via email upon approval.

Project Status

Vendora is an ongoing project, with continuous improvements and new features being added. Future updates include payment gateway integration, real-time order tracking, and a chatbot assistant to enhance user experience.

Technologies Using:

Backend:

  • Node.js: Server-side runtime environment.
  • Express.js: Web application framework for routing and middleware.

Database:

  • MongoDB: NoSQL database for data storage.

Frontend:

  • React.js: A powerful JavaScript library for building interactive and dynamic user interfaces.
  • Redux: State management to ensure a smooth and efficient user experience across the application.
  • Material Tailwind CSS: A combination of Material Design and Tailwind CSS, providing a sleek, modern, and responsive UI.

Design Tools:

  • Figma: For designing the website layout and user interface.
Key Features:
  • For Customers: Browse and purchase products effortlessly.
    Secure authentication and authorization using JWT.
    Responsive UI with Material Tailwind for a smooth user experience.
  • For Vendors: Submit an application with necessary business documents for verification.
    Get admin approval and receive login credentials via email.
  • For Admin: Review vendor applications and approve/reject them after verification.
    Monitor vendor activities and manage product listings.
Additional Features & Future Enhancements:
  • Role-based access control for vendors, customers, and admins.
  • Live notifications for new orders, vendor status updates, and admin approvals.
  • Payment gateway integration for seamless transactions.
  • Order tracking system for customers and vendors.
  • Analytics dashboard for vendors to monitor sales performance.
