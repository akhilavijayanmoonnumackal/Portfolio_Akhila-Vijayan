GVG (Data Management Application)

This is a highly interactive and efficient data management application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The application is designed for managing hierarchical plant data, allowing users to explore, modify, and organize data efficiently. It features a drilling system, right-click context menus, drag-and-drop functionality, and multiple viewing modes for an enhanced user experience.

Technologies Used

Backend:

  • Node.js: Server-side runtime environment.
  • Express.js: Web application framework for routing and middleware.

Database:

  • MongoDB: NoSQL database for data storage.

Frontend:

  • React.js: A powerful JavaScript library for building interactive and dynamic user interfaces.
  • Recoil.js: A lightweight state management library that ensures efficient and scalable state handling.
  • Material Tailwind CSS: A combination of Material Design and Tailwind CSS, providing a sleek, modern, and responsive UI.

Design Tools:

  • Figma: For designing the website layout and user interface.
Key Features:
  • Drilling System for Navigation: Clicking on any plant reveals its inner plants, enabling seamless navigation through hierarchical data.
    Double-clicking on a parent plant directly opens its child plants.
  • Right-Click Context Menu: Users can delete, edit, or create new plants through an intuitive right-click menu.
  • Multiple Viewing Modes:
  • Tree View - Displays data in a hierarchical tree structure.
  • Detail View - Provides detailed information about a selected plant.
  • Level View - Shows plant hierarchy at different levels.
  • Drag-and-Drop Functionality: Users can rearrange plants dynamically using drag-and-drop, making data organization seamless.
  • Plant Preview with Zoom: Users can preview plant details with an integrated zoom feature for better clarity.
  • Bulk Data Management:
  • CSV Bulk Import - Allows users to import large sets of plant data efficiently.
  • CSV Export - Users can export data for backup or external use.
  • PDF Download Support: Users can generate PDF reports of plant data for documentation or sharing purposes.
  • State Management with Recoil.js: The application utilizes Recoil Atoms for efficient state management, ensuring seamless interactions.
  • Modern UI with Material Tailwind CSS: The frontend is built using Material Tailwind CSS, providing a sleek and responsive user experience.
